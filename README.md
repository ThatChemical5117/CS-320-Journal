## How can I ensure that my code, program, or software is functional and secure?
Often when working on projects of large size or great complexity one can validate their code and software through rigorous testing.
Doing testing at runtime checking the different functions and components of the software makes sure that the program works to specification and that there are no obvious bugs

## How do I interpret user needs and incorporate them into a program?
Taking user needs, we can create a list of requirements from that as we break the user need apart into smaller and smaller pieces until we can get down to the technical details.
Often this process is long and requires multiple iterations before they can be made into technical requirements and then incorporated into a program

## How do I approach designing software?
The approach I like to take is to create a list of smaller problems from the user needs or wants, and continue to split those until I can get a set a requirements that can be implemented.
I then design a general outline and interface for the classes and their public functions. I then write the test code to define the functions behavior and complete the program to make the tests pass.
